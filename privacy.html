BDR Cloud Privacy Policy

Last updated: October 9, 2026

Purpose

BDR Cloud processes supported commercial vehicle diagnostic files and generates translated PDF reports.

Google Account Access

BDR Cloud uses the Gmail API with the gmail.modify permission to access an authorized mailbox, retrieve submitted diagnostic files, send completed reports, and organize processed messages.

Information Processed

Information processed may include email addresses, message metadata, diagnostic attachments, vehicle identification numbers, and vehicle diagnostic data.

Use of Information

Information is used to receive translation requests, process diagnostic files, generate PDF reports, and deliver results. Google user data is not used for advertising or sold to third parties.

Storage and Security

Processing takes place using Google Cloud services. Temporary files are used during report generation. Gmail messages and generated reports may remain in the authorized mailbox according to its retention settings. Access credentials are stored using Google Cloud Secret Manager.

Data Sharing

BDR Cloud uses Google Cloud infrastructure to operate the service. Information is not shared with unrelated third parties for marketing.

Contact

For privacy questions, contact aerecon3@gmail.com.
